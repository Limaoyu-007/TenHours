# 验证方式与边界

核心回归程序不依赖第三方测试框架，覆盖暂停/继续、工作学习分账、UI 延迟、跨零点、时钟调整、十小时阈值、补录、原子保存、损坏恢复和清单持久化。旧版 JSON 无需手动迁移。

`scripts/Verify.ps1` 在真实 WinForms 消息循环中验证按钮、托盘隐藏、系统消息处理、补录窗口、清单勾选与保存、添加/改名/删除、尺寸和实际流逝时间，生成隔离测试数据、窗口位图与短时 CPU/内存采样。过程约 75 秒，会主动制造一次保存失败提示。不会修改真实使用数据或开机启动设置。

```powershell
.\scripts\Verify.ps1
```

1.2.0 的行为回归包含 22 个核心用例和 29 个窗口断言。README 截图取自该版本的原生窗口，使用通用示例任务和模拟时间。1.3.0 已生成 Windows x64 自带运行时的 exe，尚未运行新版测试或界面验收；旧版结果不代表新版已通过验证。

1.4.0 的 25 个核心回归已通过。其中新增三个用例覆盖：每日完成快照在改名、删除、跨天及重启后保留；取消完成只影响当天且不重复记账；清单显示设置持久化且不改变管理顺序。新版窗口交互尚未进行实际界面验收。

## 结果的含义

- 窗口尺寸以 `GetDpiForWindow(HWND)` 读取的窗口 DPI 为准；当前截图在 96 DPI 下生成。
- 锁屏、休眠测试通过向真实窗口注入对应 Windows 消息完成，不能代替真实机器的锁屏/休眠验收。
- 暂停时不做每秒轮询，只安排下一次零点唤醒；正式计时每秒结算，约每五秒保存。任务操作立即保存。
- 任务勾选、重命名、删除和跨天不会改变计时总量。1.3.0 中，普通任务跨天保留完成状态，每日任务在新的一天重置勾选；程序关闭后跨天重开也会重置每日任务。
- 短时 CPU/内存数据只能说明该次运行，不能证明十小时连续运行完全无内存增长。

真实物理锁屏、休眠、注销/登录、自启、多显示器热插拔和十小时持续运行需在目标 Windows 桌面继续验收。应用不会为验收主动锁定、休眠或重启电脑。

正常退出会保存当前进度。强杀或断电可能损失最近一次检查点后的约五秒计时（UI 被系统阻塞时可能更长）；原子写入保证提交时使用完整文件替换，无法替代离线备份或消除硬件损坏。
